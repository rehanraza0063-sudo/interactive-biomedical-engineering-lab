# 🧬 Interactive Biomedical Engineering Simulation Lab

An interactive web-based learning platform for **Biomedical Engineering** that transforms lecture-note concepts into an engaging digital learning and simulation experience.

The platform combines **concept explanations, diagrams, flowcharts, interactive simulations, signal visualization, calculators, quizzes, voice explanations, and progress tracking** to make biomedical engineering topics easier to understand.

## 📚 About the Project

This project was developed as an **Interactive Digital Lecture + Simulation Laboratory** for Biomedical Engineering learning.

Instead of presenting lecture notes as static text, the platform converts important concepts into interactive learning modules.

Users can:

* 📖 Study concepts
* 📊 Explore diagrams
* 🔄 Follow interactive flowcharts
* 🧪 Run biomedical simulations
* 📈 Visualize signals and waveforms
* 🧮 Use formula-based calculators
* 🔊 Listen to topic explanations
* 📝 Take quizzes
* 🔖 Bookmark topics
* 📌 Track learning progress
* 🔍 Search topics across the modules

# 🧪 Interactive Simulations

The project includes interactive simulations designed around relevant biomedical engineering concepts.

### ❤️ Cardiac Rhythm / ECG Lab

Explore cardiac rhythm behavior and ECG-related concepts through interactive visualization.

Users can experiment with parameters and observe changes in the displayed waveform.

---

### 🩸 Electromagnetic Flow Meter

Interactive visualization of electromagnetic blood-flow measurement based on the relationship between:

* Magnetic field
* Conductive fluid
* Electrode measurement
* Flow velocity
* Induced voltage

---

### 📡 Ultrasonic Doppler Simulation

Explore Doppler-based flow measurement by changing relevant parameters and observing the resulting behavior.

---

### 💓 Cardiac Output Calculator

Interactive cardiac-output learning tool based on:

`CO = HR × SV`

where:

* **CO** = Cardiac Output
* **HR** = Heart Rate
* **SV** = Stroke Volume

---

### 🩺 Oscillometric NIBP Simulation

Interactive visualization of non-invasive blood-pressure measurement using oscillometric principles.

---

### 💉 Indicator Dilution Simulation

Explore the dilution-curve concept used in cardiac-output measurement.

The simulation visualizes the relationship between indicator concentration and time.

---

### 📊 Interactive Process Visualizations

Selected biomedical engineering processes are represented using interactive diagrams and step-by-step visualizations.

# ⚙️ Installation

## 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/interactive-biomedical-engineering-simulation-lab.git
```

Move into the project directory:

```bash
cd interactive-biomedical-engineering-simulation-lab
```

---

## 2. Install Dependencies

```bash
npm install
```

---

## 3. Start Development Server

```bash
npm run dev
```

Vite will provide a local URL similar to:

```text
http://localhost:5173
```

Open that address in your browser.

---

# 🚀 Build for Production

Run:

```bash
npm run build
```

The production files will be generated in:

```text
dist/
```

To preview the production build:

```bash
npm run preview
```

The academic learning content is based on the three provided Biomedical Engineering lecture-note documents.

The project separates the source-note content from the application interface so that the educational material can be maintained independently from the UI.

The simulations and visualizations are implemented as interactive learning aids and should be understood as educational representations rather than clinical diagnostic tools.
